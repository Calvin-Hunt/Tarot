# Project Rules

## Product Goal
Build a premium tarot + zodiac web app with strong mystical visual identity, smooth animation, clear draw logic, and maintainable code.

## Stack
- React
- Vite
- TypeScript
- Tailwind CSS
- Framer Motion

## Engineering Rules
- Keep data separate from UI
- Use clear types
- Prefer reusable components
- Avoid monolithic files
- Keep animations smooth and performant
- Ensure responsive layout
- Use professional naming

## UX Rules
- Premium mystical feeling
- Dark celestial aesthetics
- Gold-line accents
- Polished card flip animation
- Clear reading result hierarchy

## Logic Rules
- Real shuffle
- No duplicate cards in one spread
- Upright/reversed randomization
- Zodiac only enhances interpretation, never replaces tarot meaning
